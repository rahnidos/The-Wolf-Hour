# Wolf Hour: A Daggerheart Setting

This is a work-in-progress (WIP) project to create a Sci-Fi Post-Apocalyptic setting for the **Daggerheart RPG** system. The project is currently in its early stages, focusing on establishing the core world-building and lore.
